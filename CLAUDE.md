# Project instructions

## Sidebar navigation
The ink sidebar carries one contextual list below the main nav, and it MOVES with the level the
user has navigated to rather than accumulating a block per level. The kicker names the parent
(their own desk on a client record, the client on a statement of work record) and links back to
it; the rows are the siblings at the current level, with a count each, and the current one is the
bold accent row. One block, never two. This is a standing pattern, not per-screen decoration.
